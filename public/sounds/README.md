# Audio Effects Directory

Supported sound files (`.mp3` format) in `public/sounds/`:

- `move.mp3` — Normal piece move
- `capture.mp3` — Capturing an opponent piece
- `check.mp3` — Move delivering check
- `checkmate.mp3` (or `chekmate.mp3`) — Game ending in checkmate
- `castle.mp3` — Kingside or queenside castling
- `promote.mp3` — Pawn promotion
- `victory.mp3` — Player wins game
- `defeat.mp3` — Player loses game or resigns
- `draw.mp3` — Stalemate, repetition, or insufficient material
- `game-end.mp3` — General game over fallback
- `select.mp3` — Tapping / selecting a piece on the board
- `error.mp3` (or `illegal.mp3`) — Illegal move attempted
- `genericnotify.mp3` — Deep game analysis review completed
- `lowtime.mp3` — Low time warning
